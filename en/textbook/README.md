# Textbooks

The three textbooks of the [Kairos Language Exam](../README.md). Read them in grade order (Grade 3 → Grade 2 → Grade 1). Every "Run it and read" example in the text
is execution-verified, and the "▶ Open in the Playground" link under each example lets you try it in the browser as is (no installation).

- [Grade 3 Textbook — Reading](L3.md) — given a Kairos expression, read exactly what fires. Exercises: [Grade 3 sample questions](../L3/README.md)
- [Grade 2 Textbook — Writing](L2.md) — write a schedule definition yourself from a business requirement sentence. Exercises: [Grade 2 sample questions](../L2/README.md)
- [Grade 1 Textbook — Operational semantics](L1.md) — design definitions that do not betray you in operation: covering, annotations, runway, determinism and the supply boundary. Exercises: [Grade 1 sample questions](../L1/README.md)

The [language specification](https://kairos-lang.org/en/spec/) is always canonical — the textbooks only show the way and never redefine the specification.
The expected output in these materials is verified against the same version as the [Playground](https://kairos-lang.org/en/playground/) (the version is noted on the [exam top](../README.md)).
