# 1 級（運用意味論）サンプル問題 / Grade 1 sample questions

[Kairos 言語検定](../README.md)の 1 級——**運用まで設計できる**（covering・評価註釈・external・決定性）——の
サンプル問題。教本は [1 級教本 — 運用意味論](../textbook/L1.md)（各章末の「演習」がここの問題）。

- [L1-002 空テーブルと「正当な空」（出力予測）](002-empty-table.md)——教本 第 1 章
- [L1-003 SupplyError の型区別（概念）](003-supply-error-types.md)——第 5 章
- [L1-005 残走路の読み（概念）](005-runway-reading.md)——第 3 章
- [L1-008 発報層との分業（概念）](008-division-of-labor.md)——第 4 章
- [L1-011 註釈の輸送（出力予測）](011-annotation-transport.md)——第 3 章
- [L1-012 決定性（出力予測）](012-determinism.md)——第 4 章
- [L1-015 空の三分岐（出力予測）](015-empty-trichotomy.md)——第 2 章

形式: **出力予測**＝式と評価範囲から出力を答える（末尾の「検証」節を[リファレンス実装](https://github.com/azathothx/kairos-lang)か
[Playground](https://kairos-lang.org/playground/) で再現できる）・**概念**＝仕様の理解を問う（仕様の該当行が根拠）。
各問題は言語仕様の §参照つき——正本は常に[言語仕様](https://kairos-lang.org/spec/)。
