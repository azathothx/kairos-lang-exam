# 教本 / Textbooks

[Kairos 言語検定](../README.md)の教本 3 冊。級の順（3 級 → 2 級 → 1 級）に読む。本文の「動かして読む」は
すべて実行検証済みで、各例の「▶ Playground で開く」からブラウザでそのまま試せる（インストール不要）。

- [3 級教本 — 読解](L3.md)——Kairos 式を受け取って、何が発火するかを正確に読む。演習は [3 級サンプル問題](../L3/README.md)
- [2 級教本 — 作文](L2.md)——業務要件の文章から、スケジュール定義を自分で書く。演習は [2 級サンプル問題](../L2/README.md)
- [1 級教本 — 運用意味論](L1.md)——covering・註釈・残走路・決定性・供給の境界まで、運用で裏切られない定義を設計する。演習は [1 級サンプル問題](../L1/README.md)

正本は常に[言語仕様](https://kairos-lang.org/spec/)——教本は道筋を示すだけで、仕様を再定義しない。
教材の期待出力は [Playground](https://kairos-lang.org/playground/) と同じ版で検証している（版は[検定トップ](../README.md)に記す）。
